# Carpeta Knowledge

Esta carpeta almacena el material de referencia (apuntes, guías gramaticales, listas de vocabulario, etc.) en texto plano (`.txt`, `.md`).

## Uso por el Tutor:
- **Prioridad 1**: Siempre que se revise o fundamente una corrección gramatical, el agente revisará primero los documentos de texto plano ubicados en esta carpeta.
- Puedes agregar tus propios archivos de reglas gramaticales, listas de errores frecuentes o apuntes de clase aquí para que el tutor los priorice al responderte.
